# Actions couplées & phases d’équipe

## Structure d’un round

| Phase | Qui | Temps |
|---|---|---|
| Phase équipe A | Tous les A en parallèle | 45–70 s selon format |
| Résolution A | Lockstep | Court |
| Phase équipe B | Tous les B | Idem |
| Environnement | Marée, ticks… | Auto |

Formats : **2v2** (~50 s) · **3v3** (~60 s) · **4v4** (~70 s).

---

## Règles communes combos

| Paramètre | Valeur |
|---|---|
| Adrénaline équipe | 0–100 partagée |
| Max / phase | 1 Duo/Salve (+ 1 Ulti si jauge OK) |
| Portée couple | ≤ 25 m (sauf ulti) |
| Soft fail | Combo dégradé si ≥50 % rôles ≥ OK |

### Flow invite
Proposer (C / ping Combo) → alliés Y/N (8–12 s) → QTE couplé (rôles) → score collectif → résolution fin de phase.

### Rôles QTE
**Tempo** (rythme) · **Force** (mash) · **Précision** (clics/trace) · **Ancrage** (hold)

## Catalogue des 8 techniques

### 1. Liane-Bélier — Duo · 2j · ⚡25
Tempo + Force. Tire hors cover + charge + stun. Sync = armor break. Maps : Canopée ★★★★★

### 2. Tir croisé — Focus · 2–3j · ⚡20
Précision ×N. Multi ×1.4/1.7/2.0. Sync = perforant 50 % cover. Cirque ★★★★★

### 3. Salve d’ananas — Artillerie · 2–4j · ⚡35
Zone Map + fuse. Vagues AOE. Sync = super-explosion + chunk. Marée ★★★★★

### 4. Cocotte-minute — Piège · 2j · ⚡15
Ancrage + Tempo. Pose + déclenche. Sync = +rayon + silence 1ʳᵉ note.

### 5. Mains vertes — Soin · 2j · ⚡20
Ancrage + Tempo lent. Gros soin + cleanse. Sync = petit heal zone + bouclier 1 hit.

### 6. Mur de la Horde — Défensif · 2–4j · ⚡30
Tous Ancrage. −40 % dégâts prochaine phase ennemie. Sync = −60 % + riposte.

### 7. Pont de singes — Terrain · 2–3j · ⚡25
Précision (tracé) + Force. Passerelle 2 phases. Sync = renforcée + zip.

### 8. Banane d’Or — Ulti · 2–4j · ⚡100
4 rôles. Mega AOE + chunk. Sync = cratère + execute &lt;15 % PV.

**MVP unlock :** 1, 2, 3, 5, 8 · puis 4, 6, 7.

## Wireflow 3v3 (exemple, 60 s)

- 0:00 phase start, Map live  
- 0:03 ping Focus B2  
- 0:05–0:18 moves parallèles  
- 0:20–0:28 Tir croisé A1+A2  
- 0:30–0:38 Mains vertes A3→A1 + grenade solo A2  
- 0:60 lockstep : moves → soins → combos → solos → terrain → phase B  

Ordre résolution fixe et déterministe (serveur autoritaire).
