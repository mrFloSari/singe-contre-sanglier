Budgets ref : move/tour ~12–16 m · match 8–14 tours.

## Map 1 — La Canopée Fêlée

Jungle verticale post-tempête. ~80×55 m.

### Strates
| Code | Hauteur | Sol | Move |
|---|---|---|---|
| B Bas | 0 | terre/racines | ×1 (boue ×1.3) |
| M Milieu | +4–6 m | lianes | ×1.1 singe / ×1.4 sanglier |
| N Nids | +9–12 m | feuillage | exposé |

### Spawns 1v1 / 2v2
- Singe : B1 ouest · Sanglier : B2 est  
- 2v2 : B1+N3 vs B2+B3  

### POI
Totem banane (M1, +6 PV) · Liane fragile destructible · Cache noix (B3) · Nid central M3  

### Flow
Bas → contest carrefour M1 → nid pour lob → casser liane = bascule mobilité.

## Map 3 — Le Cirque des Os (PvP cœur)

Arène ~70 m diam. Carcasse de titan.

### Strates
A sable 0 · G1 +3 · G2 +6 · G3/V pont +9 · S crâne 0/−1  

### Spawns 2v2
Duo Ouest (C Ouest + G1) vs Duo Est (C Est + G1)

### POI
Pont Vertèbre (2 hits = chute) · Brasero (révèle Map 1 tour) · Tambour (miss 1ʳᵉ note QTE) · Ossements-cover  

### Flow
Test centre → prise G2 → menace pont → crâne reset → final arène/pont.

---

## Map 4 — La Marée des Coques

Cimetière de navires. ~90×50 m. **Eau monte.**

| Rounds | Eau | Effet |
|---|---|---|
| 1–3 | Basse | P1 jouable |
| 4–6 | Moyenne | P1 lent + 3 dmg/fin tour |
| 7+ | Haute | P1 impassable · P2 dangereux |

### Spawns
Singe SO → C1 · Sanglier SE → C2  

### POI
Nid-de-pie (légendaire) · Soute caraque · Tonneaux poudre · Vague knockback tours 4 et 7  

### Flow
Rush loot bas → marée force la montée → combats sur coques → clutch sniper / P3.
