# UI sync + kits 2v2

## HUD TPS

- PV self + portrait allié (pastille BOT si besoin)  
- Adrénaline équipe (10 segments)  
- Timer phase (orange &lt;15 s, rouge &lt;5 s)  
- Mini-Map coin  

## Pings (Q maintenu)

Ici · Attention · Focus cible · Soigne-moi · Combo · Ulti  

## Catalogue combo (C)

Liste filtrée (distance, munitions, ADR, éligibilité). Bouton **Proposer**.

## Prompt Rejoindre

`A1 propose TIR CROISÉ → B2 | Rôle : Précision | [Y] [N] | 0:09`

## Overlay QTE couplé

Titre + portraits · module individuel · piste sync commune · scores live · récap 1,2 s.

## Caméras combo

| Joueurs | Affichage |
|---|---|
| 2 | Split ou caméra duo |
| 3–4 | Ciné fixe + overlays QTE |

## Résolution

Liste ordonnée des actions + Skip → transition phase adverse.
